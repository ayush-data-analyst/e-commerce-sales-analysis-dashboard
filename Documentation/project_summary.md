# Project Summary

The E-Commerce Sales Analysis Dashboard was created to evaluate sales performance across categories, states, payment methods, and sales channels.

Using Microsoft Excel, the project transformed raw transactional data into interactive business reports and visual dashboards.

The analysis focused on:

- Revenue tracking
- Product performance
- Customer purchasing behavior
- Return and cancellation trends
- Channel effectiveness
- State-level performance

The dashboard supports data-driven decision-making through KPI monitoring and business insights.
